# tools/

Operator extras (not shipped as malware helpers).

| File | Role |
| --- | --- |
| `activate.win.cmd` | Default: opens `ms-settings:activation`. Replace with your own `activate.win` if needed. |
| `Bginfo64.exe` | Optional: drop Sysinternals BGInfo here for one-click launch |

The GUI looks in: next to `WindowsLab.exe\tools`, `%LocalAppData%\WindowsLab\tools`, and this repo `tools\`.
